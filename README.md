# Scinapse Agent

A smart research assistant built with Streamlit, `pypdf`, and Google Gemini API, designed to help students and researchers analyze PDF documents seamlessly. Developed for academic use at the University of Hafr Al-Batin.

## Features
- **PDF Document Processing:** Extract and analyze text from multiple research papers or PDF files.
- **Google Gemini Integration:** Powered by advanced AI to summarize, explain, and answer questions based on the uploaded content.
- **Security Best Practice:** Includes a manual API key input system within the UI to securely manage credentials.
- **Interactive UI:** A clean, user-friendly interface built using Streamlit.
